## Repository Name
xrwvm-fullstack_developer_capstone

## Project Name
Cars Dealership Web Application – Full-stack Developer Capstone Project

## Description
A responsive full-stack web application for a national car retailer in the U.S. that displays dealership branches and allows users to view and submit reviews.

## Technologies
- Frontend: React, HTML, CSS, Bootstrap
- Backend: Django, Node.js (Express), Flask
- Databases: MongoDB, SQLite
- Sentiment Analysis: Flask microservice on IBM Cloud Code Engine
- Deployment: Docker, Kubernetes
- CI/CD: GitHub Actions
